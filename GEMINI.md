# Project Guidelines & Permanent Rules

## Tool Page Architecture Standard (Mandatory for ALL Tools)
Every current and future tool page in this project MUST follow this 4-part structure:
1. **Calculator on Top**: Interactive tool above the fold.
2. **300-500 words Explanation**:
   - ما هي الأداة وما أهميتها؟ (What is the tool?)
   - كيفية الاستخدام خطوة بخطوة (How to use step-by-step)
   - مثال عملي بالأرقام (Practical real-world numeric example)
3. **FAQ Section (الأسئلة الشائعة)**:
   - 3 to 5 real questions with thorough answers.
   - Includes JSON-LD `FAQPage` schema so Google features it in "People Also Ask".
4. **Related Tools (أدوات ذات صلة)**:
   - Internal linking to other tools in the site to boost SEO juice and user retention.
