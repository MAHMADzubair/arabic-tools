# Tool Page Architecture Standard

Every tool page in this project MUST strictly adhere to the following 4-part layout structure:

1. **Top**: Interactive Calculator Component (above the fold)
2. **Detailed Explanation (300-500 words in Arabic)**:
   - **ما هي هذه الأداة؟** (What is this tool and how does it work)
   - **كيفية الاستخدام خطوة بخطوة** (Step-by-step guide to using the tool)
   - **مثال تطبيقي عملي بالأرقام** (Concrete numerical practical example)
3. **FAQ Section (الأسئلة الشائعة)**:
   - 3 to 5 common questions & answers that users and Google "People Also Ask" search for.
   - Include JSON-LD `FAQPage` structured schema for SEO rich snippets.
4. **Related Tools (أدوات مالية ذات صلة)**:
   - Internal links with icons and brief descriptions pointing to the other available financial tools.
